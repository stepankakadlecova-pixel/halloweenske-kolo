# Halloweenské kolo — Pro malé dobrodruhy

Statická stránka s 20 poli, pěti pevnými kupony a jedním zatočením v prohlížeči.

Veřejný web: https://pmd-halloweenske-kolo-2026.stepanka-kadlecova.chatgpt.site

Kódy a podmínky se mění v poli prizes v app.js. Kupony musí být aktivovány v e-shopu. Uzamčení používá localStorage, takže není omezením na osobu.

Pro spuštění otevřete index.html přes statický webserver.
